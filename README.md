# AIROGS - AI-based Recommendation System

Responsive web app built with Java, HTML, CSS, JavaScript + Machine Learning

## Tech Stack
- Java, HTML, CSS, JavaScript
- Python, Pandas, Scikit-learn (for data processing)
- Git, GitHub

## Features
- Responsive design & Dynamic functionality
- User query classification using ML model
- Smart recommendations based on user input

## Dataset Details (For Interview)
- Dataset: User queries collected and cleaned using Pandas
- Features: User keywords, category, search pattern
- Label: Recommended category / response
- Algorithm: Classification model (Train-Test split 80-20)
